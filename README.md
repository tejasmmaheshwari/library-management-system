# Library Management System

## Project Overview
A Python-based Library Management System that helps manage book records and perform common library operations through a command-line interface (CLI) and a graphical user interface (GUI).

## Technologies Used
- Python
- Tkinter for the graphical user interface
- JSON for storing book records

## Features
- Add new books
- Search for books
- Issue books
- Return books
- Manage book records using a JSON data file

## Project Structure
- `library_cli.py` — command-line application
- `library_gui.py` — graphical user interface
- `books.json` — book data storage

## Setup Instructions

### Prerequisites
Install Python 3.x on your computer.

### Run the Application
Clone or download the repository and open a terminal in the project folder.

To run the command-line version:

```bash
python library_cli.py
```

To launch the graphical interface:

```bash
python library_gui.py
```

No additional third-party packages are required if Tkinter is available in your Python installation.
